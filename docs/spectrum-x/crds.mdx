A Spectrum-X Kubernetes deployment uses CRDs from several NVIDIA operators
working together. This page documents the **Spectrum-X Operator** CRDs
(v1alpha2 — `SpectrumXRailPoolConfig`). For the other CRDs, see the
linked references. For the full stack of operators, drivers, and CNIs that
own these CRDs and how they depend on each other, see
[Architecture and Components](/spectrum-x/components).

| CRD | Owner | Role |
| --- | --- | --- |
| `NicClusterPolicy` | NVIDIA Network Operator | Cluster-wide operator configuration. Enables NIC Configuration Operator, NV-IPAM, Spectrum-X Operator, and secondary network components. |
| `NicConfigurationTemplate` | NIC Configuration Operator | Per-NIC firmware and Spectrum-X settings (link type, `numVfs`, multiplane mode, RA version). See [Spectrum-X NIC Configuration](/spectrum-x/spectrum-x-configuration). |
| `NicInterfaceNameTemplate` | NIC Configuration Operator | Predictable rail / plane-based netdev and RDMA names driven by udev rules. |
| `CIDRPool` | NV-IPAM | Per-rail IP allocation pool consumed by `SpectrumXRailPoolConfig`. |
| [SpectrumXRailPoolConfig](/spectrum-x/crds#spectrumxrailpoolconfig) | Spectrum-X Operator | Rail topology, PF selection, IPAM binding, and DRA / SR-IOV resource exposure (full API below). |
| `ResourceClaimTemplate` | Kubernetes DRA | Pod-to-GPU+VF binding via Dynamic Resource Allocation (Kubernetes upstream resource). |

Packages:

- [spectrumx.nvidia.com/v1alpha2](/spectrum-x/crds#spectrumxnvidiacomv1alpha2)

## spectrumx.nvidia.com/v1alpha2

Package v1alpha2 contains API Schema definitions for the spectrumx v1alpha2 API group.

Resource Types:

- [SpectrumXRailPoolConfig](/spectrum-x/crds#spectrumxrailpoolconfig)

### SpectrumXRailPoolConfig

SpectrumXRailPoolConfig is the Schema for the spectrumxrailpoolconfigs API.

| Field | Description |
| --- | --- |
| `apiVersion` | `spectrumx.nvidia.com/v1alpha2` |
| `kind` | `SpectrumXRailPoolConfig` |
| `metadata` | Standard object metadata. Refer to the Kubernetes API documentation for the fields of the `metadata` field. |
| `spec`<br />[SpectrumXRailPoolConfigSpec](/spectrum-x/crds#spectrumxrailpoolconfigspec) | Desired state of the SpectrumXRailPoolConfig. |
| `status`<br />[SpectrumXRailPoolConfigStatus](/spectrum-x/crds#spectrumxrailpoolconfigstatus) | Observed state of the SpectrumXRailPoolConfig. |

### SpectrumXRailPoolConfigSpec

(*Appears on:* [SpectrumXRailPoolConfig](/spectrum-x/crds#spectrumxrailpoolconfig))

SpectrumXRailPoolConfigSpec defines the desired state of SpectrumXRailPoolConfig.

| Field | Description |
| --- | --- |
| `draEnabled`<br />bool | *(Optional)* Enables Dynamic Resource Allocation (DRA) for the configured Spectrum-X nodes. Defaults to `true`. |
| `vfStateFollow`<br />bool | *(Optional)* Mirrors PF carrier loss to active VF representors. When all PFs in a rail topology report `NO-CARRIER`, its VF representors are set administratively down so Pods receive a link-down notification. Defaults to `true`. Recovery of any PF restores the representors; setting `false` also restores them and disables following. |
| `nodeSelector`<br />map[string]string | *(Optional)* Label selector that identifies the Spectrum-X nodes the configuration applies to. |
| `maxUnavailable`<br />[IntOrString](https://godoc.org/k8s.io/apimachinery/pkg/util/intstr#IntOrString) | *(Optional)* Either an integer count or a percentage of nodes in the pool that can be configured in parallel. Defaults to `1`. |
| `networkNamespace`<br />string | *(Optional)* Namespace of the NetworkAttachmentDefinition custom resource. |
| `ovsConfig`<br />map[string]string | *(Optional)* Additional `ovs-vswitchd` `other_config` entries, merged over the operator defaults. Matching keys override the default value. See [OVS settings and switch-plane offsets](/spectrum-x/components#ovs-settings-and-switch-plane-offsets). |
| `numVfs`<br />int | Number of VFs to configure on each PF. Must be `>= 1`. |
| `railTopology`<br />[[]RailTopology](/spectrum-x/crds#railtopology) | Rails topology list. Must contain at least one entry. |

### SpectrumXRailPoolConfigStatus

(*Appears on:* [SpectrumXRailPoolConfig](/spectrum-x/crds#spectrumxrailpoolconfig))

SpectrumXRailPoolConfigStatus defines the observed state of SpectrumXRailPoolConfig.

| Field | Description |
| --- | --- |
| `syncStatus`<br />string | Synchronization status. One of `Unknown`, `InProgress`, `Failed`, `Succeeded`. |
| `nodeStates`<br />[[]NodeState](/spectrum-x/crds#nodestate) | *(Optional)* Per-node view of the observed state, giving a finer-grained picture than the aggregate `syncStatus`. |
| `observedGeneration`<br />int64 | The most recent generation observed by the controller. |

### NodeState

(*Appears on:* [SpectrumXRailPoolConfigStatus](/spectrum-x/crds#spectrumxrailpoolconfigstatus))

NodeState defines a finer-grained view of the observed state of SpectrumXRailPoolConfig on a single node.

| Field | Description |
| --- | --- |
| `name`<br />string | Name of the node this state refers to. |
| `state`<br />string | State of the node configuration. One of `Unknown`, `InProgress`, `Failed`, `Succeeded`. |
| `observedGeneration`<br />int64 | *(Optional)* The `SpectrumXRailPoolConfig` generation this node state was reported for. |
| `message`<br />string | *(Optional)* Human-readable message with details about why the node is in this state. |

### RailTopology

(*Appears on:* [SpectrumXRailPoolConfigSpec](/spectrum-x/crds#spectrumxrailpoolconfigspec))

RailTopology describes a single rail in the Spectrum-X pool. Only one of `cidrPoolRef` or `ipam` may be specified.

| Field | Description |
| --- | --- |
| `name`<br />string | Rail topology name. Must be non-empty. |
| `nicSelector`<br />[NicSelector](/spectrum-x/crds#nicselector) | PF selector identifying the NICs that belong to this rail. |
| `cidrPoolRef`<br />string | *(Optional)* Reference to a CIDR Pool resource. Mutually exclusive with `ipam`. |
| `ipam`<br />string | *(Optional)* Advanced IPAM configuration. Mutually exclusive with `cidrPoolRef`. |
| `mtu`<br />int | MTU for the rail. Must be `>= 0`. |
| `swPlane`<br />int | *(Optional)* Switch-plane offset for Hardware Multiplane entries that select multiple PFs. Must be `>= 0`; omitted means `0`. Switch-plane numbers start at `len(pfNames) * swPlane` and follow the order in `pfNames`. This field does not change the NIC plane count. |

### NicSelector

(*Appears on:* [RailTopology](/spectrum-x/crds#railtopology))

NicSelector selects the physical functions that participate in a rail.

| Field | Description |
| --- | --- |
| `pfNames`<br />[]string | List of PF names. Must contain at least one entry. |
