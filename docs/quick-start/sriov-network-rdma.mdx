<Note>
These manifests are the Kubernetes Launch Kit render for preset `PowerEdge-XE9680-H200` and release catalog `26.10` (`v26.10.0` component images on `nvcr.io/nvidia/mellanox`). The staging coordinates in `docs/common/vars.yml` are a separate release record. Multirail stays at the Launch Kit default, so each east-west rail is its own document in the pool, policy, and network files. Install the Network Operator chart before applying these custom resources. Helm `values.yaml` is omitted.

```bash
l8k generate \
  --for PowerEdge-XE9680-H200 \
  --node-selector "nvidia.com/gpu.product=NVIDIA-H200" \
  --network-operator-release 26.10 \
  --fabric ethernet \
  --deployment-type sriov \
  --skip-network-operator-helm \
  --save-deployment-files ./deployment
```

For the Launch Kit discover, deploy, and validate flow, see [Configuration Assistance with Kubernetes Launch Kit](/k8s-launch-kit/k8s-launch-kit).
</Note>

**Step 4**: Prepare the SR-IOV operator for NIC configuration

This example applies a `NicConfigurationTemplate` and a `SriovNetworkNodePolicy`. The [Quick Start Helm install](/quick-start/quick-start-k8s#install-network-operator-helm-chart) only enables the SR-IOV operator. Apply both settings below before the template. Otherwise the SR-IOV config daemon and the NIC Configuration Operator change the same NIC at the same time.

Upgrade the chart so the config daemon waits until NIC configuration finishes, and enable the Maintenance Operator that the NIC Configuration Operator uses:

```bash
helm upgrade network-operator nvidia/network-operator \
  -n nvidia-network-operator \
  --reuse-values \
  --version {{network-operator-version}} \
  --set maintenanceOperator.enabled=true \
  --set-json 'sriov-network-operator.sriovOperatorConfig.configDaemonNodeSelector={"beta.kubernetes.io/os":"linux","network.nvidia.com/operator.mofed.wait":"false","network.nvidia.com/operator.nic-configuration.wait":"false"}'
```

Disable the SR-IOV Network Operator `mellanox` plugin:

```bash
kubectl patch sriovoperatorconfigs.sriovnetwork.openshift.io -n nvidia-network-operator default --patch '{ "spec": { "disablePlugins": ["mellanox"]} }' --type='merge'
```

The full requirements are in [Use of NIC Configuration Operator together with SR-IOV Network Operator](/nic-conf-operator/nic-fw-configuration#use-of-nic-configuration-operator-together-with-sr-iov-network-operator).
