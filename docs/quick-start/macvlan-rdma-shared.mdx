**Step 1**: Create NicClusterPolicy with RDMA shared device

<Code src="../../examples/processed/macvlan-rdma-shared/10-nicclusterpolicy.yaml" language="yaml" />

```bash
kubectl apply -f nicclusterpolicy.yaml
```

**Step 2**: Create IPPool for nv-ipam

<Code src="../../examples/processed/macvlan-rdma-shared/20-ippool.yaml" language="yaml" />

```bash
kubectl apply -f ippool.yaml
```

**Step 3**: Create MacvlanNetwork

<Code src="../../examples/processed/macvlan-rdma-shared/30-macvlannetwork.yaml" language="yaml" />

```bash
kubectl apply -f macvlannetwork.yaml
```

**Step 4**: Deploy test workload

<Code src="../../examples/processed/macvlan-rdma-shared/40-pod.yaml" language="yaml" />

```bash
kubectl apply -f pod.yaml
```

Verify the deployment:

```bash
kubectl exec -it macvlan-test-pod -- ip addr show
kubectl exec -it macvlan-test-pod -- ibv_devinfo
```
