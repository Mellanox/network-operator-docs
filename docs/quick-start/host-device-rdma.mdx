**Step 1**: Create NicClusterPolicy with host device support

<Code src="../../examples/processed/host-device-rdma/10-nicclusterpolicy.yaml" language="yaml" />

```bash
kubectl apply -f nicclusterpolicy.yaml
```

**Step 2**: Create IPPool for nv-ipam

<Code src="../../examples/processed/host-device-rdma/20-ippool.yaml" language="yaml" />

```bash
kubectl apply -f ippool.yaml
```

**Step 3**: Create HostDeviceNetwork

<Code src="../../examples/processed/host-device-rdma/30-hostdevicenetwork.yaml" language="yaml" />

```bash
kubectl apply -f hostdevicenetwork.yaml
```

**Step 4**: Deploy test workload

<Code src="../../examples/processed/host-device-rdma/40-pod.yaml" language="yaml" />

```bash
kubectl apply -f pod.yaml
```

Verify the deployment:

```bash
kubectl exec -it hostdev-test-pod -- lspci | grep Mellanox
```
