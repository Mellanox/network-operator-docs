## NicClusterPolicy CRD

To change `NicClusterPolicy` CRD object manually without helm you need to change `nic-cluster-policy` CR like a regular Kubernetes resource. For more information on NicClusterPolicy custom resource, please refer to the [Network-Operator Project Sources](https://github.com/Mellanox/network-operator#nicclusterpolicy-crd).
